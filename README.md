This is a [Next.js](https://nextjs.org) project bootstrapped as a Knockrow Distillers starter,
following the same conventions as the Volpino build.

Read `BUILD_BRIEF.md` first — it lists what's built, what's still placeholder, and what content
is needed before this is ready to go live. `CLAUDE.md` has notes for continuing the build with
Claude Code.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see it.

## Deploy on Vercel

Push this repo to GitHub, then import it into [Vercel](https://vercel.com/new). No environment
variables are required yet (the enquiry form isn't wired to an email provider).
